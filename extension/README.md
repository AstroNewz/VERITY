# Verity Brand Guard — Chromium In-Situ Browser Extension

> **Round 3 Feature Delivery**: Seamless, in-situ brand governance directly inside LinkedIn, Twitter/X, WordPress, Gmail, Notion, and any web-based CMS.

---

## ⚡ 60-Second Setup for Judges (Chrome, Brave, Edge)

1. Open your Chromium browser and navigate to:
   ```text
   chrome://extensions/
   ```
2. Enable **Developer mode** (toggle switch in the top-right corner).
3. Click **"Load unpacked"** in the top-left corner.
4. Select the `extension/` directory located inside this project:
   ```text
   Verity_CodeAxis/extension
   ```
5. Pin **Verity Brand Guard** to your browser toolbar!

---

## 🚀 How to Test & Demo

### Option A: In-Situ Floating Chip on Any Webpage
1. Highlight any marketing copy or post on any web page (e.g. `"NovaFest 2026 is back and it is CHEAP!"`).
2. A yellow **`🛡️ Check with Verity`** chip will immediately appear above your selection.
3. Click the chip — Verity's in-situ modal will pop up, citing the exact rule violations and unverified claims with 1-click replacement fixes!

### Option B: Extension Popup Quick Checker
1. Click the **Verity Guard** icon in your browser toolbar.
2. Click **"Demo"** to populate a test post containing tone errors, unverified superlative claims, and confidential terms.
3. Click **"🔍 Run Verity Check"** — watch cited rules (`T-3`, `C-1`, `P-1`) and ledger sources appear instantly with 1-click fixes.
